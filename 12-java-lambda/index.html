☕ Modul Pembelajaran Java
Belajar Java Lambda
Dari anonymous class yang verbose ke lambda yang elegan — panduan lengkap Functional Programming untuk PHP/Laravel developer yang belajar Java.
😩 Masalah: Anonymous Class Terlalu Verbose

Sebelum Java 8, untuk meneruskan "sebuah perilaku" ke method, kamu harus membuat anonymous class:

// Hanya untuk print satu nilai — kode 5 baris untuk hal sepele!
list.forEach(new Consumer<String>() {
    @Override
    public void accept(String value) {
        System.out.println(value);
    }
});

Kode di atas hanya ingin melakukan satu hal: print value. Tapi harus menulis 5 baris boilerplate. Ini membuat kode susah dibaca dan lambat ditulis.

✨ Solusi: Lambda Expression (Java 8+)
// Sama persis hasilnya — cukup 1 baris!
list.forEach(value -> System.out.println(value));

// Atau lebih ringkas dengan Method Reference:
list.forEach(System.out::println);

Lambda memungkinkan kamu menulis fungsi inline secara ringkas. Ini adalah fondasi Functional Programming di Java.

🐘 Analogi PHP/Laravel: Closure

Di PHP, kamu sudah sangat familiar dengan Closure (anonymous function):

// PHP Closure
$greet = function($name) {
    return "Hello " . $name;
};

// Arrow function PHP 7.4+
$greet = fn($name) => "Hello " . $name;

// Laravel Collection
collect($names)->each(fn($name) => print($name));

Java Lambda adalah konsep yang identik — anonymous function yang bisa disimpan dalam variabel dan diteruskan ke method lain. Sintaksnya sedikit berbeda, tapi spiritnya sama.

Chapter 1 • Fondasi
🔷 Functional Interface & @FunctionalInterface
Syarat agar sebuah interface bisa digunakan sebagai lambda — harus punya tepat satu abstract method.

Lambda di Java bekerja di atas konsep Functional Interface: sebuah interface yang memiliki tepat satu abstract method. Lambda adalah implementasi ringkas dari abstract method tersebut.

// File: SimpleAction.java
package programmer.zaman.now.lambda;

@FunctionalInterface            // Anotasi penanda — opsional tapi sangat disarankan
public interface SimpleAction {

    String action(String name); // Satu-satunya abstract method

    // Interface boleh punya default method atau static method,
    // tapi abstract method hanya boleh SATU untuk jadi Functional Interface.
}
@FunctionalInterface
Anotasi dari Java 8. Fungsinya seperti compile-time guard: jika kamu tidak sengaja menambahkan abstract method kedua, compiler akan langsung error. Opsional tapi sangat disarankan — membuat intent jelas.
String action(String name)
Satu abstract method. Lambda yang mengimplementasikan SimpleAction harus menerima satu String dan mengembalikan String. Signature ini menjadi "kontrak" yang harus dipenuhi lambda.
💡 Bagaimana Lambda "Masuk" ke Interface

Saat kamu menulis SimpleAction action = name -> "Hello " + name;, compiler Java tahu bahwa lambda ini adalah implementasi dari method action(String name). Ini karena SimpleAction hanya punya satu abstract method — tidak ada ambiguitas.

❌ Bukan Functional Interface
// Dua abstract method = bukan FI
interface NotFunctional {
    void method1();
    void method2(); // ❌ Ini bikin error
    // @FunctionalInterface akan reject ini
}
✅ Functional Interface yang Valid
@FunctionalInterface
interface Valid {
    void doSomething();    // Satu abstract
    default void helper(){} // default OK
    static void util(){}    // static OK
}
🐘 Analogi PHP: Interface dengan __invoke

Di PHP, sebuah class bisa berlaku seperti fungsi jika mendefinisikan method __invoke(). Di Java, Functional Interface adalah konsep yang jauh lebih formal dan type-safe: kompiler tahu persis signature-nya dan bisa melakukan type checking pada lambda.

Chapter 2 • Sintaks
✍️ Sintaks Lambda — 5 Bentuk Penulisan
Lambda bisa ditulis dalam berbagai bentuk dari yang paling eksplisit sampai paling ringkas — semuanya menghasilkan hal yang sama.

Java memberikan fleksibilitas penulisan lambda. Dari yang paling verbose sampai paling ringkas — pilih sesuai konteks dan keterbacaan.

1
Paling Eksplisit — Tipe parameter + kurung kurawal + return
SimpleAction simpleAction1 = (String value) -> {
    return "Hello " + value;
};

Tipe String ditulis eksplisit. Body dalam blok {}. Harus pakai return.

2
Tanpa tipe — type inference oleh compiler
SimpleAction simpleAction2 = (name) -> {
    return "Hello " + name;
};

Compiler tahu tipe parameter dari signature FI. Tipe tidak perlu ditulis ulang.

3
Expression body — tanpa kurung kurawal (satu ekspresi)
SimpleAction simpleAction3 = (String value) -> "Hello " + value;

Jika body hanya satu ekspresi: hapus {} dan return. Nilai ekspresi otomatis di-return.

4
Tanpa tipe + expression body
SimpleAction simpleAction4 = (value) -> "Hello " + value;

Kombinasi bentuk 2 dan 3. Paling umum dipakai saat ada beberapa parameter.

5
Paling Ringkas — tanpa tanda kurung (satu parameter)
SimpleAction simpleAction5 = value -> "Hello " + value;

Jika hanya satu parameter: tanda kurung () boleh dihapus. Paling ringkas!

📌 Aturan Ringkas Sintaks Lambda
KondisiBoleh dihapus?
Tipe parameter✅ Ya — compiler bisa infer dari FI
Tanda kurung () parameter✅ Ya — jika hanya satu parameter
Kurung kurawal {} body✅ Ya — jika hanya satu ekspresi
Keyword return✅ Ya — jika body adalah expression (tanpa {})
Tanda kurung () jika tidak ada parameter❌ Tidak — () wajib
Tanda kurung () jika ada dua+ parameter❌ Tidak — (a, b) -> wajib
🐘 Analogi PHP: Arrow Function Evolution
// PHP: banyak cara juga
$greet1 = function(string $name): string { return "Hello " . $name; }; // Eksplisit
$greet2 = function($name) { return "Hello " . $name; };                  // Tanpa tipe
$greet3 = fn($name) => "Hello " . $name;                                 // Arrow function PHP 7.4+

Evolusi yang mirip! Java lambda (bentuk 5) dan PHP arrow function adalah konsep yang sangat serupa. Perbedaan: PHP menggunakan =>, Java menggunakan ->.

Pertanyaan: Lambda mana yang TIDAK valid secara sintaks Java?

value -> "Hello " + value
(a, b) -> a + b
a, b -> a + b (dua parameter tanpa kurung)
Chapter 3 • Built-in Functional Interface
📤 Supplier<T> — Penyedia Data
Tidak terima input, tapi menghasilkan output — seperti pabrik yang memproduksi nilai saat diperlukan.

Java 8 menyediakan banyak Functional Interface siap pakai di package java.util.function. Kamu tidak perlu buat dari nol seperti SimpleAction. Supplier adalah yang paling sederhana: tanpa input, ada output.

// File: SupplierApp.java
import java.util.function.Supplier;

public class SupplierApp {
    public static void main(String[] args) {

        // Supplier: tidak ada parameter, hanya return value
        //       () -> "nilai"
        Supplier<String> supplier = () -> "Eko Kurniawan Khannedy";

        // .get() untuk mengambil nilai dari Supplier
        System.out.println(supplier.get()); // Eko Kurniawan Khannedy

        // Contoh lain:
        Supplier<Integer> randomNum = () -> (int)(Math.random() * 100);
        Supplier<List<String>> emptyList = () -> new ArrayList<>();
    }
}
Supplier<String>
Interface bawaan Java dengan signature: T get(). Type parameter T adalah tipe nilai yang di-supply. Di sini T = String artinya get() akan mengembalikan String.
() -> "Eko Kurniawan Khannedy"
Lambda tanpa parameter (kurung kosong () wajib). Body langsung ekspresi yang di-return. Nilainya baru "diproduksi" saat .get() dipanggil — ini fondasi lazy evaluation!
supplier.get()
Method untuk mengeksekusi Supplier dan mendapatkan hasilnya. Setiap panggilan .get() menjalankan ulang lambda — jika lambda melakukan komputasi berat, ini bisa jadi latency concern.
🐘 Analogi PHP: Closure tanpa parameter
// PHP: Closure tanpa parameter = Supplier
$supplier = fn() => "Eko Kurniawan Khannedy";
echo $supplier(); // Eko Kurniawan Khannedy

// Laravel: lazy loading via Closure
$value = Cache::remember('key', 3600, function() {
    return DB::table('users')->get(); // Hanya dieksekusi jika cache kosong
});

Pola Cache::remember() di Laravel adalah contoh nyata penggunaan "Supplier" — closure hanya dieksekusi jika cache miss. Ini adalah lazy evaluation!

Chapter 4 • Built-in Functional Interface
📥 Consumer<T> — Pemroses Data
Menerima input tapi tidak menghasilkan output — dipakai untuk side effects seperti print, logging, atau menyimpan data.
// File: ConsumerApp.java
import java.util.function.Consumer;

public class ConsumerApp {
    public static void main(String[] args) {

        // Consumer: terima satu parameter, tidak return apapun (void)
        Consumer<String> consumer = value -> System.out.println(value);

        // .accept(value) untuk menjalankan Consumer
        consumer.accept("Eko Kurniawan"); // Eko Kurniawan

        // Contoh lain:
        Consumer<Integer> printDouble = n -> System.out.println(n * 2);
        Consumer<String> saveToDb    = name -> database.save(name); // side effect

        // Consumer chaining dengan .andThen()
        Consumer<String> printAndLog = consumer.andThen(
            value -> System.out.println("Logged: " + value)
        );
        printAndLog.accept("Eko"); // Print "Eko", lalu print "Logged: Eko"
    }
}
Consumer<String>
Interface bawaan dengan signature: void accept(T t). Return type void — Consumer hanya untuk side effects (print, log, simpan, dll), bukan menghasilkan nilai.
value -> System.out.println(value)
Lambda satu parameter, body satu ekspresi (method call). Karena return type-nya void, tidak ada nilai yang dikembalikan.
.andThen() — Consumer Chaining
Consumer bisa digabungkan dengan andThen() untuk membentuk pipeline side effects. Consumer pertama dieksekusi, lalu Consumer kedua. Ini adalah Function Composition.
🐘 Analogi PHP: each() di Laravel Collection
// Laravel Collection each() = Consumer
collect($names)->each(function($name) {
    echo $name; // void — tidak return
});

// PHP arrow function
collect($names)->each(fn($name) => print($name));
Chapter 5 • Built-in Functional Interface
📥📥 BiConsumer<T, U> — Consumer Dua Parameter
Seperti Consumer tapi menerima dua input — dipakai di Map.forEach() untuk iterasi key-value.
// File: MapForEachApp.java (bagian BiConsumer)
import java.util.function.BiConsumer;

// BiConsumer: terima DUA parameter, tidak return apapun (void)
map.forEach(new BiConsumer<String, String>() {
    @Override
    public void accept(String key, String value) {
        System.out.println(key + ":" + value);
    }
});

// Versi lambda (jauh lebih ringkas):
map.forEach((key, value) -> System.out.println(key + ":" + value));
BiConsumer<String, String>
Interface bawaan dengan signature: void accept(T t, U u). Dua type parameter (bisa berbeda tipe). Map.forEach() secara internal menggunakan BiConsumer untuk key dan value.
(key, value) -> ...
Lambda dengan dua parameter — harus pakai kurung (). Nama parameter bebas, tapi gunakan yang deskriptif. Karena dua parameter, tidak boleh tanpa kurung.
💡 Pola Bi-xxx di java.util.function

Java menyediakan versi "Bi" untuk interface yang butuh dua parameter: BiConsumer<T,U>, BiFunction<T,U,R>, BiPredicate<T,U>. Pattern-nya konsisten — tinggal tambah "Bi" di depan untuk versi dua-parameter.

🐘 Analogi PHP: each() dengan index
// PHP: array_walk = BiConsumer (value, key)
array_walk($map, function($value, $key) {
    echo "$key:$value";
});

// Laravel Collection
collect($map)->each(function($value, $key) {
    echo "$key:$value";
});
Chapter 6 • Built-in Functional Interface
❓ Predicate<T> — Pengujian Kondisi
Menerima input dan mengembalikan boolean — dipakai untuk filter, validasi, dan pengujian kondisi.
// File: PredicateApp.java
import java.util.function.Predicate;

public class PredicateApp {
    public static void main(String[] args) {

        // Predicate: terima satu parameter, return boolean
        Predicate<String> predicateCheckBlank = value -> value.isBlank();

        System.out.println(predicateCheckBlank.test(""));    // true (kosong)
        System.out.println(predicateCheckBlank.test("Eko")); // false (tidak kosong)

        // Predicate composition:
        Predicate<String> isNotBlank = predicateCheckBlank.negate(); // Negasi
        Predicate<String> isBlankOrShort = predicateCheckBlank
            .or(value -> value.length() < 3);                         // OR
        Predicate<String> isNotBlankAndLong = predicateCheckBlank
            .negate()
            .and(value -> value.length() > 10);                       // AND
    }
}
Predicate<String>
Interface bawaan dengan signature: boolean test(T t). Sering dipakai di List.removeIf(), Stream.filter(), dan validasi kondisi.
.test()
Method untuk menjalankan Predicate dan mendapatkan hasil boolean. Namanya "test" karena ini tentang menguji/mengetes suatu kondisi.
.negate() / .and() / .or()
Default methods untuk komposisi Predicate. negate() = NOT, and() = AND, or() = OR. Bisa di-chain untuk membuat kondisi kompleks secara ekspresif tanpa nested if.
🐘 Analogi PHP: filter() di Collection
// PHP: callable yang return bool = Predicate
$isNotBlank = fn($value) => !blank($value);

// Laravel Collection filter = menerima Predicate
$filtered = collect($names)->filter(fn($name) => strlen($name) > 5);

// PHP array_filter = sama
$filtered = array_filter($names, fn($name) => strlen($name) > 5);

Chapter 7 • Built-in Functional Interface
⚙️ Function<T, R> — Transformasi Data
Menerima input tipe T dan menghasilkan output tipe R — transformasi murni, fondasi dari Stream.map().
// File: FunctionApp.java
import java.util.function.Function;

public class FunctionApp {
    public static void main(String[] args) {

        // Function: terima T, return R
        Function<String, Integer> functionLength = value -> value.length();
        //         ↑input         ↑output
        // String masuk, Integer keluar

        System.out.println(functionLength.apply("Eko")); // 3
        System.out.println(functionLength.apply("Eko Kurniawan")); // 13

        // Contoh lain:
        Function<String, String> toUpper = String::toUpperCase;
        Function<Integer, String> toStr  = n -> "Number: " + n;

        // Function composition: andThen() dan compose()
        Function<String, String> lengthToStr = functionLength.andThen(toStr);
        // "Eko" -> length 3 -> "Number: 3"
        System.out.println(lengthToStr.apply("Eko")); // Number: 3
    }
}
Function<String, Integer>
Interface bawaan dengan signature: R apply(T t). Dua type parameter: T = tipe input, R = tipe output. Bisa berbeda tipe (String → Integer) atau sama (String → String).
.apply()
Method untuk menjalankan Function. Berbeda dari Predicate (.test()) dan Consumer (.accept()) dan Supplier (.get()) — setiap FI punya method invoke yang berbeda nama.
.andThen() — Function Composition
f.andThen(g) menghasilkan fungsi baru yang menjalankan f dulu, lalu hasilnya diteruskan ke g. Ini adalah function composition — fondasi dari Stream API: stream.map(f).map(g).
📌 Ringkasan 4 Built-in Functional Interface Utama
Supplier<T>
T get()
❌ Input → ✅ Output
Pabrik nilai, lazy load
Consumer<T>
void accept(T)
✅ Input → ❌ Output
Side effects (print, log)
Predicate<T>
boolean test(T)
✅ Input → boolean
Filter, validasi
Function<T,R>
R apply(T)
✅ Input → ✅ Output
Transformasi data
🐘 Analogi PHP: map() di Collection
// PHP: callable yang transform = Function
$getLength = fn(string $s): int => strlen($s);

// Laravel Collection map = Function
$lengths = collect($names)->map(fn($name) => strlen($name));

// PHP array_map
$lengths = array_map(fn($name) => strlen($name), $names);

Chapter 8 • Method Reference
🔗 Method Reference — Lambda yang Lebih Ringkas
Shortcut untuk lambda yang hanya memanggil satu method — menggunakan sintaks ClassName::methodName.

Jika sebuah lambda hanya berisi panggilan ke satu method yang sudah ada, kamu bisa mempersingkatnya dengan Method Reference.

// File: MethodReferenceApp.java + StringUtil.java

// StringUtil: utility class dengan static method
public class StringUtil {
    public static boolean isLowerCase(String value) {
        for (var c : value.toCharArray()) {
            if (!Character.isLowerCase(c)) return false;
        }
        return true;
    }
}

// ─── Referensi ke static method ───
// Lambda (verbose):
Predicate<String> p1 = value -> StringUtil.isLowerCase(value);

// Method Reference (ringkas):
Predicate<String> p2 = StringUtil::isLowerCase;
//                     ClassName::methodName

System.out.println(p2.test("eko")); // true
System.out.println(p2.test("Eko")); // false

// ─── Referensi ke instance method dari parameter ───
// Lambda (verbose):
Function<String, String> f1 = (String value) -> value.toUpperCase();

// Method Reference (ringkas):
Function<String, String> f2 = String::toUpperCase;
//                           Tipe::instanceMethod
// "Ambil parameter String, panggil .toUpperCase() padanya"

System.out.println(f2.apply("Eko")); // EKO
StringUtil::isLowerCase
Static Method Reference: ClassName::staticMethod. Parameter lambda otomatis diteruskan ke method. Ekuivalen dengan value -> StringUtil.isLowerCase(value).
String::toUpperCase
Instance Method Reference pada Parameter: ClassName::instanceMethod. Parameter lambda menjadi objek yang method-nya dipanggil. Ekuivalen dengan value -> value.toUpperCase().
// ─── Referensi ke instance method dari objek tertentu ───
public void run() {
    // this::methodName — method dari objek saat ini
    Predicate<String> p1 = this::isLowerCase;
    System.out.println(p1.test("eko")); // true
}

public void run2() {
    MethodReferenceApp app = new MethodReferenceApp();

    // object::methodName — method dari objek tertentu
    Predicate<String> p2 = app::isLowerCase;
    System.out.println(p2.test("eko")); // true
}

public boolean isLowerCase(String value) {
    for (var c : value.toCharArray()) {
        if (!Character.isLowerCase(c)) return false;
    }
    return true;
}
this::isLowerCase
Instance Method Reference (this): method dari objek saat ini (this). Ekuivalen dengan value -> this.isLowerCase(value). Berguna untuk meneruskan method instans saat ini ke API lain.
app::isLowerCase
Instance Method Reference (objek tertentu): method dari objek spesifik. Ekuivalen dengan value -> app.isLowerCase(value). Variabel app "di-capture" oleh lambda.
📋 4 Jenis Method Reference
JenisSintaksEkuivalen Lambda
Static methodClass::staticMethodx -> Class.staticMethod(x)
Instance method (parameter)Class::instanceMethodx -> x.instanceMethod()
Instance method (this)this::methodx -> this.method(x)
Instance method (objek)obj::methodx -> obj.method(x)
🐘 Analogi PHP: First-class callable PHP 8.1
// PHP 8.1: First-class callable — mirip Method Reference!
$strlen  = strlen(...);          // ekuivalen Java: String::length
$strtoupper = strtoupper(...);   // ekuivalen Java: String::toUpperCase

// Sebelum PHP 8.1:
$fn = 'strlen';   // atau
$fn = [obj, 'methodName'];

// Laravel: menggunakan callable array
collect($names)->map([Str::class, 'upper']);

Chapter 9 • Lambda in Action
🔄 forEach List — Evolusi Perulangan
Menelusuri elemen List dari cara klasik (for loop) → anonymous class → lambda → method reference.
// File: ForEachApp.java
List<String> list = List.of("Eko", "Kurniawan", "Khannedy");

// ─── Cara 1: Classic for loop ───
for (var value : list) {
    System.out.println(value);
}

// ─── Cara 2: forEach dengan Anonymous Class ───
list.forEach(new Consumer<String>() {
    @Override
    public void accept(String value) {
        System.out.println(value);
    }
});

// ─── Cara 3: forEach dengan Lambda ───
list.forEach(value -> System.out.println(value));

// ─── Cara 4: forEach dengan Method Reference (paling ringkas) ───
list.forEach(System.out::println);
List.of()
Factory method Java 9+ untuk membuat List immutable secara ringkas. Equivalent PHP: ['Eko', 'Kurniawan', 'Khannedy']. List yang dibuat dengan List.of() tidak bisa dimodifikasi (add() akan throw exception).
for (var value : list)
Enhanced for loop — cara iterasi paling basic. var (Java 10+) untuk type inference. Ekuivalen PHP: foreach ($list as $value).
list.forEach()
Method dari Iterable interface yang menerima Consumer<T>. Cara modern iterasi di Java 8+. Lebih ekspresif dan bisa dikomposisi.
System.out::println
Method Reference ke instans System.out: System.out adalah objek bertipe PrintStream, dan println adalah method-nya. Ini adalah instance method reference ke objek tertentu — System.out di-"capture".
🐘 Analogi PHP/Laravel
$list = ['Eko', 'Kurniawan', 'Khannedy'];

// Classic foreach
foreach ($list as $value) { echo $value; }

// Laravel Collection each() = Java forEach
collect($list)->each(fn($value) => print($value));

// PHP array_walk
array_walk($list, fn($value) => print($value));
Chapter 10 • Lambda in Action
🗺️ forEach Map — Iterasi Key-Value
Iterasi Map menggunakan BiConsumer — karena Map memiliki dua nilai per entry: key dan value.
// File: MapForEachApp.java
Map<String, String> map = new HashMap<>();
map.put("first_name",  "Eko");
map.put("middle_name", "Kurniawan");
map.put("last_name",   "Khannedy");

// ─── Cara 1: Classic for loop via entrySet() ───
for (var entry : map.entrySet()) {
    System.out.println(entry.getKey() + ":" + entry.getValue());
}

// ─── Cara 2: forEach dengan Anonymous BiConsumer ───
map.forEach(new BiConsumer<String, String>() {
    @Override
    public void accept(String key, String value) {
        System.out.println(key + ":" + value);
    }
});

// ─── Cara 3: forEach dengan Lambda ───
map.forEach((key, value) -> System.out.println(key + ":" + value));
map.entrySet()
Cara iterasi Map secara klasik: entrySet() mengembalikan Set<Map.Entry<K,V>>, lalu setiap entry bisa diakses .getKey() dan .getValue(). Lebih verbose dibanding lambda.
map.forEach((key, value) -> ...)
Map.forEach() menerima BiConsumer<K,V> secara internal. Lambda dua parameter (key, value) jauh lebih bersih daripada mengakses entry.getKey() dan entry.getValue().
🐘 Analogi PHP: foreach dengan key-value
$map = ['first_name' => 'Eko', 'last_name' => 'Khannedy'];

// Classic foreach with key
foreach ($map as $key => $value) { echo "$key:$value"; }

// Laravel Collection
collect($map)->each(fn($value, $key) => print("$key:$value"));

🗑️ removeIf — Hapus Elemen dengan Predicate
Menghapus elemen dari koleksi berdasarkan kondisi — menggunakan Predicate, jauh lebih aman dari for loop biasa.
// File: RemoveIfApp.java
List<String> names = new ArrayList<>();
names.addAll(List.of("Eko", "Kurniawan", "Khannedy"));

// ─── Cara SALAH: menghapus saat iterasi for loop ───
// JANGAN LAKUKAN INI — ConcurrentModificationException!
// for (var name : names) {
//     if (name.length() > 5) {
//         names.remove(name); // ❌ Modifikasi saat iterasi = EXCEPTION!
//     }
// }

// ─── Cara dengan Anonymous Predicate ───
names.removeIf(new Predicate<String>() {
    @Override
    public boolean test(String value) {
        return value.length() > 5; // Hapus jika panjang > 5
    }
});

// ─── Cara Lambda (paling bersih) ───
names.removeIf(name -> name.length() > 5);

System.out.println(names); // [Eko] — "Kurniawan" (9) dan "Khannedy" (8) dihapus
ConcurrentModificationException — Bahaya For Loop
Menghapus elemen dari Collection saat sedang di-iterate via for-each loop akan menyebabkan ConcurrentModificationException. Ini adalah bug klasik Java yang susah di-debug. removeIf() menyelesaikan ini dengan aman!
names.removeIf()
Method dari Collection interface (Java 8+) yang menerima Predicate<E>. Semua elemen yang memenuhi predicate (return true) akan dihapus. Aman dari ConcurrentModificationException karena dikelola internal Collection.
new ArrayList<>() vs List.of()
Perlu ArrayList (bukan List.of()) karena removeIf membutuhkan List yang mutable. List.of() menghasilkan immutable List. names.addAll(List.of(...)); adalah cara idiomatis membuat mutable List dengan nilai awal.
🐛 Bug Klasik: ConcurrentModificationException
❌ Berbahaya
for (var name : names) {
    if (name.length() > 5)
        names.remove(name);
    // ConcurrentModificationException!
}
✅ Aman
names.removeIf(
    name -> name.length() > 5
);
// Bersih, aman, mudah dibaca

Chapter 12 • Lambda in Action
💤 Lazy Evaluation dengan Supplier
Menunda eksekusi kode sampai benar-benar diperlukan — menggunakan Supplier untuk efisiensi.
// File: LazyApp.java
public class LazyApp {
    public static void main(String[] args) {
        testScore(60, () -> getName());
        // Atau lebih ringkas dengan method reference:
        // testScore(60, LazyApp::getName);
    }

    public static void testScore(int score, Supplier<String> name) {
        if (score > 80) {
            System.out.println("Selamat " + name.get() + ", Anda Lulus");
            // name.get() HANYA dipanggil jika score > 80
        } else {
            System.out.println("Coba Lagi Tahun Depan");
            // name.get() TIDAK dipanggil — getName() tidak dieksekusi!
        }
    }

    public static String getName() {
        System.out.println("Method getName() dipanggil"); // Tracking eksekusi
        return "Eko";
    }
}
() -> getName() — Supplier sebagai Lazy Wrapper
Lambda ini tidak langsung memanggil getName() — ia hanya membungkus panggilan tersebut. getName() baru akan dieksekusi saat name.get() dipanggil di dalam method.
Eager vs Lazy
Eager (langsung): testScore(60, getName()) — getName() langsung dieksekusi saat memanggil testScore(), meskipun hasilnya tidak dipakai (score 60 ≤ 80). Lazy (ditunda): testScore(60, () -> getName()) — getName() hanya dieksekusi jika benar-benar diperlukan.
❌ Eager — getName() selalu dipanggil
// getName() dipanggil dulu, baru hasilnya dikirim
testScore(60, getName());
// Output:
// "Method getName() dipanggil" ← dipanggil!
// "Coba Lagi Tahun Depan"
// Sia-sia karena score 60 tidak lulus
✅ Lazy — getName() hanya dipanggil jika perlu
// Supplier membungkus getName(), tidak langsung dipanggil
testScore(60, () -> getName());
// Output:
// "Coba Lagi Tahun Depan"
// Tidak ada "Method getName() dipanggil"!
// Efisien — getName() tidak dieksekusi percuma
💡 Kapan Lazy Evaluation Sangat Berguna

Bayangkan getName() adalah query database berat, atau API call ke service eksternal. Dengan Supplier (lazy), kamu bisa menghindari biaya tersebut jika ternyata hasilnya tidak dipakai. Ini adalah optimasi performa yang penting di sistem dengan logika kondisional.

    return User::find($id); // Hanya dipanggil jika cache miss!

Chapter 13 • Optional
🎁 Optional<T> — Nilai yang Mungkin Null
Container untuk nilai yang bisa ada atau tidak ada — solusi elegan untuk menghindari NullPointerException tanpa if-null yang bertumpuk.
// File: OptionalApp.java
public class OptionalApp {
    public static void main(String[] args) {
        sayHello("Eko");   // Nama ada
        sayHello(null);    // Nama null
    }

    public static void sayHello(String name) {

        // ─── Cara lama: if null check ───
        // if (name != null) {
        //     String upperName = name.toUpperCase();
        //     System.out.println("HELLO " + upperName);
        // } else {
        //     System.out.println("HELLO TEMAN");
        // }

        // ─── Cara modern: Optional chain ───
        String upperName = Optional.ofNullable(name)  // 1. Bungkus nilai (boleh null)
            .map(String::toUpperCase)                   // 2. Transform jika ada (lambda/MR)
            .orElse("TEMAN");                           // 3. Nilai default jika null

        System.out.println("HELLO " + upperName);
        // "Eko"  → HELLO EKO
        // null   → HELLO TEMAN
    }
}
Optional.ofNullable(name)
Membungkus nilai ke dalam Optional. ofNullable() menerima nilai yang mungkin null. Jika null, menghasilkan Optional.empty(). Alternatif: Optional.of(value) yang akan throw exception jika null, dan Optional.empty() yang langsung kosong.
.map(String::toUpperCase)
Transformasi nilai di dalam Optional jika nilainya ada (tidak kosong). Menerima Function<T, R>. Jika Optional kosong (null), map() di-skip dan tetap kosong — tidak ada NullPointerException!
.orElse("TEMAN")
Mengambil nilai dari Optional, atau menggunakan nilai default jika Optional kosong. Alternatif: orElseGet(() -> computeDefault()) untuk lazy default, orElseThrow() untuk throw exception jika kosong.
Optional.ofNullable("Eko") → Optional["Eko"] (present)
.map(String::toUpperCase) → Optional["EKO"] (transform)
.orElse("TEMAN") → "EKO" (value present, default not used)
Optional.ofNullable(null) → Optional.empty() (absent)
.map(String::toUpperCase) → Optional.empty() (skipped — no value!)
.orElse("TEMAN") → "TEMAN" (value absent, default used) 
Optional<String> opt = Optional.ofNullable(name);

// ─── Mengambil nilai ───
String val = opt.get();             // ❌ NoSuchElementException jika kosong
String val = opt.orElse("default"); // ✅ Default value (eager)
String val = opt.orElseGet(() -> computeDefault()); // ✅ Default lazy (Supplier)
String val = opt.orElseThrow();     // ✅ Throw NoSuchElementException
String val = opt.orElseThrow(() -> new CustomException()); // Throw custom

// ─── Eksekusi kondisional ───
opt.ifPresent(v -> System.out.println(v)); // Jalankan jika ada
opt.ifPresentOrElse(
    v -> System.out.println("Ada: " + v),  // Jika ada
    () -> System.out.println("Tidak ada")  // Jika kosong
);

// ─── Transformasi ───
Optional<String> upper = opt.map(String::toUpperCase);
Optional<String> flatOpt = opt.flatMap(v -> Optional.of(v.trim())); // Hindari Optional<Optional>

// ─── Filter ───
Optional<String> longOnly = opt.filter(v -> v.length() > 3);

// ─── Cek status ───
boolean present = opt.isPresent(); // true jika ada nilai
boolean empty   = opt.isEmpty();   // true jika kosong (Java 11+)
🐘 Analogi Laravel: Optional Helper & Null Object Pattern
// PHP: null coalescing operator
$name = $user?->name ?? 'Teman'; // Elvis + null safe

// Laravel optional() helper

// Analoginya:

    ?->strtoupper()           // transform jika ada

Java Optional adalah versi formal dan type-safe dari PHP null coalescing. Optional memaksa kamu untuk eksplisit menangani kasus null, sementara PHP ?? lebih implicit.

💡 Key Insights untuk PHP Developer
λ Lambda = Typed Closure

Java Lambda adalah PHP Closure tapi dengan tipe yang kuat. Setiap lambda harus kompatibel dengan Functional Interface yang tepat — compiler akan periksa.

🔷 @FunctionalInterface = Kontrak

Gunakan anotasi ini di setiap interface yang intended jadi FI. Ini dokumentasi sekaligus compile-time guard dari penambahan method tidak sengaja.

🔗 Method Reference = Singkatan

Jika lambda hanya berisi satu method call, ganti dengan method reference. Lebih ringkas dan lebih ekspresif. System.out::println lebih bersih dari v -> System.out.println(v).

💤 Supplier = Lazy

Bungkus komputasi mahal dalam Supplier jika tidak selalu diperlukan. Ini adalah pola lazy evaluation — sama seperti Cache::remember() di Laravel.

🎁 Optional = Anti-Null

Gunakan Optional untuk nilai yang mungkin null — terutama sebagai return type method. Jauh lebih ekspresif dari if (x != null) yang bertumpuk.

🚀 Pondasi Stream API

Lambda adalah kunci untuk belajar Stream API selanjutnya. stream.filter(Predicate), stream.map(Function), stream.forEach(Consumer) — semua memakai FI yang sudah dipelajari di sini!
