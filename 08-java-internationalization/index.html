Java Internationalization

Modul belajar mandiri untuk developer PHP/Laravel yang migrasi ke Java. Kita akan belajar cara Java mengelola bahasa, format angka, mata uang, tanggal, dan pesan teks secara multi-bahasa.

Mini Quiz

🧠 Perbedaan Mindset: Java vs PHP

Sebelum masuk ke kode, ada beberapa perbedaan fundamental antara Java dan PHP yang perlu kamu pahami. Ini bukan cuma soal sintaks — ini soal cara berpikir.

1
Strongly-typed vs Loosely-typed
Di PHP, $angka = "100" otomatis bisa dihitung sebagai angka. Di Java, tipe data WAJIB dideklarasikan secara eksplisit: int angka = 100;. Compiler Java akan menolak kode yang tipe datanya tidak cocok — ini bukan bug, ini fitur keamanan.
Mindset #1
2
Kompilasi vs Interpretasi
PHP dibaca dan dieksekusi langsung (interpreted). Java dikompilasi dulu menjadi bytecode (.class), lalu dijalankan oleh JVM. Artinya banyak error yang di PHP baru ketahuan saat runtime, di Java sudah ketahuan saat compile time.
Mindset #2
3
Locale sebagai First-Class Citizen
Di Laravel, i18n biasanya diatur lewat config app.locale global. Di Java, setiap operasi formatting bisa mendapat Locale yang berbeda secara individual. Ini lebih fleksibel, tapi juga lebih eksplisit — kamu harus selalu sadar "format ini untuk locale mana?"
Mindset #3
4
Exception Handling Wajib
Java punya checked exception — beberapa exception WAJIB di-handle dengan try-catch, tidak bisa diabaikan. Ini berbeda dengan PHP yang lebih permisif. Contoh: ParseException saat parsing tanggal/angka harus selalu ditangani.
Mindset #4
💡 Tentang Package java.util dan java.text

Semua kelas yang akan kita pelajari berasal dari dua package bawaan Java: java.util (Locale, ResourceBundle, Currency) dan java.text (NumberFormat, DateFormat, MessageFormat, ChoiceFormat). Kamu tidak perlu tambah dependency apapun — ini sudah built-in di JDK!

⚠️ Catatan: Kode Indonesia di Java

Menariknya, Java menggunakan kode bahasa "in" untuk Bahasa Indonesia (bukan "id"). Ini karena Java mengikuti standar lama ISO 639-1. Jadi selalu gunakan new Locale("in", "ID") untuk Indonesia.

Chapter 1
🌍 Locale

Locale adalah objek yang mewakili kombinasi bahasa + negara. Ini adalah fondasi dari seluruh sistem i18n Java. Seperti "identitas budaya" yang memberi tahu Java: "format ini untuk orang Indonesia" atau "format ini untuk orang Amerika."

Apa itu Locale?

Locale terdiri dari dua komponen utama: kode bahasa (2 huruf, lowercase) dan kode negara (2 huruf, uppercase). Misalnya "in" = Bahasa Indonesia, "ID" = Indonesia (negara).

// LocaleTest.java
@Test
void testNewLocale() {
    var language = "in";    // Kode bahasa: "in" untuk Indonesia
    var country = "ID";     // Kode negara: "ID" untuk Indonesia
    var locale = new Locale(language, country);

    System.out.println(locale.getLanguage());       // Output: in
    System.out.println(locale.getCountry());        // Output: ID
    System.out.println(locale.getDisplayLanguage()); // Output: Indonesian
    System.out.println(locale.getDisplayCountry()); // Output: Indonesia
}

@Test
void testNewLocaleUs() {
    var language = "en";   // English
    var country = "US";    // United States
    var locale = new Locale(language, country);

    System.out.println(locale.getLanguage());       // Output: en
    System.out.println(locale.getCountry());        // Output: US
    System.out.println(locale.getDisplayLanguage()); // Output: English
    System.out.println(locale.getDisplayCountry()); // Output: United States
}
Bedah Baris per Baris
Baris Kode Penjelasan
3 var language = "in" Kode bahasa ISO 639-1. Untuk Indonesia gunakan "in" (bukan "id"). Java mengikuti standar lama.
4 var country = "ID" Kode negara ISO 3166-1 alpha-2. Selalu uppercase.
5 new Locale(language, country) Membuat objek Locale. Constructor menerima (language, country). Ini bukan koneksi ke server — hanya objek nilai (value object) di memory.
7 getLanguage() Mengembalikan kode bahasa raw ("in").
9 getDisplayLanguage() Mengembalikan nama bahasa yang human-readable dalam bahasa default JVM ("Indonesian").
🔗 Analogi Laravel

Di Laravel, locale diatur global via config/app.php → 'locale' => 'id'. Di Java, Locale adalah objek yang bisa kamu bawa ke mana saja. Bayangkan kalau di Laravel kamu bisa memanggil __('pesan', [], 'id') dan __('message', [], 'en') sekaligus dalam satu request — itulah fleksibilitas Locale di Java.

✅ Best Practice

Gunakan konstanta bawaan seperti Locale.US, Locale.JAPAN, Locale.UK daripada membuat Locale manual untuk locale yang umum. Lebih aman dan tidak typo. Sayangnya tidak ada Locale.INDONESIA bawaan, jadi untuk Indonesia tetap harus new Locale("in", "ID").

❌ Salah — Kode negara salah case
// Kode negara harus UPPERCASE
new Locale("in", "id"); // SALAH! "id" bukan "ID"
new Locale("IN", "ID"); // SALAH! bahasa harus lowercase
✅ Benar — Konsisten dengan standar ISO
// language lowercase, country UPPERCASE
new Locale("in", "ID"); // ✅ Benar untuk Indonesia
new Locale("en", "US"); // ✅ Benar untuk Amerika

Chapter 2
📦 ResourceBundle

ResourceBundle adalah mekanisme Java untuk memuat file terjemahan berdasarkan Locale. Ini adalah padanan langsung dari folder lang/ di Laravel. Kamu bisa punya file message.properties, message_in_ID.properties, dan message_en_US.properties.

Bagaimana Cara Kerjanya?

ResourceBundle bekerja dengan sistem naming convention file. Jika kamu memanggil ResourceBundle.getBundle("message", locale), Java akan mencari file di classpath dengan urutan:

1
message_in_ID.properties (spesifik bahasa + negara)
2
message_in.properties (hanya bahasa)
3
message.properties (default/fallback)

File .properties adalah file teks biasa berisi pasangan key-value:

# message_in_ID.properties (untuk Indonesia)
hello=Halo
goodbye=Selamat Tinggal
welcome.message=Halo {0}, selamat datang di {1}

# message_en_US.properties (untuk Amerika / fallback)
hello=Hello
goodbye=Goodbye
welcome.message=Hello {0}, welcome to {1}
// ResourceBundleTest.java
@Test
void testResourceBundle() {
    // Tanpa locale → menggunakan default JVM
    var resourceBundle = ResourceBundle.getBundle("message");

    System.out.println(resourceBundle.getString("hello"));   // Hello
    System.out.println(resourceBundle.getString("goodbye")); // Goodbye
}

@Test
void testResourceBundleIndonesia() {
    var indonesia = new Locale("in", "ID");
    // Java mencari: message_in_ID.properties → message_in.properties → message.properties
    var resourceBundle = ResourceBundle.getBundle("message", indonesia);

    System.out.println(resourceBundle.getString("hello"));   // Halo
    System.out.println(resourceBundle.getString("goodbye")); // Selamat Tinggal
}

@Test
void testResourceBundleNotFound() {
    // Locale "en_US" tidak punya file khusus → fallback ke message.properties
    var us = new Locale("en", "US");
    var resourceBundle = ResourceBundle.getBundle("message", us);

    System.out.println(resourceBundle.getString("hello"));   // Hello (dari default)
}

@Test
void testResourceBundleMultipleTimes() {
    var indonesia = new Locale("en", "US");
    var resourceBundle1 = ResourceBundle.getBundle("message", indonesia);
    var resourceBundle2 = ResourceBundle.getBundle("message", indonesia);

    // Output: true — ResourceBundle di-cache! Panggilan kedua tidak baca ulang file
    System.out.println(resourceBundle1 == resourceBundle2);
}
Bedah Baris per Baris
KodePenjelasan
ResourceBundle.getBundle("message") Method statis (seperti facade Laravel). Parameter "message" adalah nama base dari file properties. File harus ada di src/main/resources/.
getBundle("message", locale) Versi dengan Locale. Java akan melakukan lookup dengan urutan fallback seperti dijelaskan di atas.
resourceBundle.getString("hello") Mengambil nilai berdasarkan key. Persis seperti __('hello') di Laravel. Jika key tidak ditemukan, akan melempar MissingResourceException.
resourceBundle1 == resourceBundle2 Ini adalah perbandingan referensi objek (bukan nilai). true berarti kedua variabel menunjuk ke objek yang SAMA di memory — bukti bahwa ResourceBundle menggunakan internal cache untuk efisiensi. Di PHP tidak ada konsep ini karena tiap request fresh.
🔗 Analogi Laravel

Di Laravel, kamu punya resources/lang/id/messages.php dan resources/lang/en/messages.php. Di Java, konsepnya sama persis: src/main/resources/message_in_ID.properties dan src/main/resources/message_en_US.properties. Pemanggilan ResourceBundle.getBundle("message", locale) setara dengan app()->setLocale('id'); __('messages.hello');. Bedanya: Java bisa set locale per-operasi, tanpa mengubah state global aplikasi.

⚠️ Common Mistake: Key Tidak Ditemukan

Jika kamu memanggil getString("kunci_yang_tidak_ada"), Java akan melempar MissingResourceException saat runtime. Di PHP, __('kunci.tidak.ada') hanya mengembalikan string kunci itu sendiri tanpa error. Selalu pastikan key ada di file properties, atau gunakan try-catch untuk menangani kemungkinan ini.

❌ Salah — File di lokasi yang salah
// File message.properties diletakkan di
// src/main/java/ ← SALAH!
// Java tidak akan menemukannya
var rb = ResourceBundle.getBundle("message");
// → Akan throw MissingResourceException
✅ Benar — File di resources folder
// File harus di:
// src/main/resources/message.properties ✅
// src/main/resources/message_in_ID.properties ✅
var rb = ResourceBundle.getBundle("message");
// → Berhasil dimuat

Chapter 3
🔢 NumberFormat

NumberFormat adalah kelas untuk memformat dan mem-parsing angka sesuai konvensi lokal. Di Indonesia, pemisah ribuan pakai titik (1.000.000), di Amerika pakai koma (1,000,000). NumberFormat mengurus semua ini secara otomatis.

Format & Parse Angka

Format = mengubah angka (double/int) menjadi String yang enak dibaca. Parse = kebalikannya, mengubah String kembali menjadi angka.

// NumberFormatTest.java

@Test
void testNumberFormat() {
    // Tanpa locale → gunakan default JVM (biasanya US untuk server)
    var numberFormat = NumberFormat.getInstance();
    var format = numberFormat.format(10000000.255);
    System.out.println(format); // Output (jika JVM US): 10,000,000.255
}

@Test
void testNumberFormatIndonesia() {
    var indonesia = new Locale("in", "ID");
    var numberFormat = NumberFormat.getInstance(indonesia);
    var format = numberFormat.format(10000000.255);
    System.out.println(format); // Output: 10.000.000,255
    // Perhatikan: titik untuk ribuan, koma untuk desimal — kebalikan dari US!
}

@Test
void testNumberFormatParseIndonesia() {
    var indonesia = new Locale("in", "ID");
    var numberFormat = NumberFormat.getInstance(indonesia);

    try {
        // Parse string format Indonesia kembali ke double
        var result = numberFormat.parse("10.000.000,255").doubleValue();
        System.out.println(result); // Output: 1.0000000255E7 (= 10000000.255)
    } catch (ParseException e) {
        // ParseException adalah CHECKED EXCEPTION → wajib ditangani!
        System.out.println("Error parse : " + e.getMessage());
    }
}
Bedah Baris per Baris
KodePenjelasanUnder the Hood
NumberFormat.getInstance() Factory method (static) untuk membuat instance NumberFormat. Ini adalah pola Factory Pattern — kamu tidak memanggil new NumberFormat() langsung. Mengembalikan subclass konkret dari NumberFormat (biasanya DecimalFormat) yang sudah dikonfigurasi sesuai locale.
numberFormat.format(10000000.255) Mengubah double ke String. Method ini thread-safe jika dipanggil pada instance berbeda, tapi tidak thread-safe jika instance yang sama dipakai dari multiple thread. Membaca konfigurasi DecimalFormatSymbols yang berisi karakter pemisah ribuan dan desimal untuk locale tersebut.
numberFormat.parse("...") Mengembalikan Number (supertype), bukan double. Makanya perlu panggil .doubleValue(). Melempar ParseException (checked) jika format tidak sesuai. Parse dilakukan dari kiri ke kanan. Jika karakter pertama tidak bisa diparse, langsung lempar exception.
💡 Insight: Thread Safety

Instance NumberFormat (dan semua Format class di Java) tidak thread-safe. Jangan simpan satu instance sebagai variabel static atau singleton yang diakses concurrent. Di aplikasi Spring Boot, buat instance baru setiap kali diperlukan, atau gunakan ThreadLocal.

🔗 Analogi Laravel

Di Laravel/PHP, kamu biasanya pakai number_format(10000000.255, 3, ',', '.') untuk format Indonesia. Parameter harus diisi manual setiap kali. Di Java, cukup buat NumberFormat.getInstance(indonesia) sekali, dan semua aturan formatting (titik, koma, jumlah desimal) sudah otomatis ter-konfigurasi sesuai locale. Lebih DRY (Don't Repeat Yourself)!

❌ Salah — Parse tanpa locale yang tepat
// Pakai locale US untuk parse angka format Indonesia
var usFormat = NumberFormat.getInstance(Locale.US);
// String "10.000.000,255" diparse sebagai US
// US membaca "10.000" = 10 (titik ribuan)
// Tapi ",255" tidak valid → error atau hasil salah!
var result = usFormat.parse("10.000.000,255");
✅ Benar — Locale harus konsisten
// Gunakan locale yang SAMA saat format dan parse
var id = new Locale("in", "ID");
var fmt = NumberFormat.getInstance(id);
String str = fmt.format(10000000.255);   // format ke ID
Number n   = fmt.parse(str);             // parse dari ID
// Konsisten → tidak ada ambiguitas!

Chapter 4
💰 Currency & NumberFormat Currency

Java menyediakan kelas Currency untuk informasi mata uang (nama, kode, simbol) dan method NumberFormat.getCurrencyInstance() untuk format/parse angka dalam format mata uang lokal.

Informasi Mata Uang dengan Kelas Currency
// CurrencyTest.java

@Test
void testCurrencyIndonesia() {
    var indonesia = new Locale("in", "ID");
    // Currency.getInstance() mengambil mata uang dari locale
    var currency = Currency.getInstance(indonesia);

    System.out.println(currency.getDisplayName());       // Indonesian Rupiah
    System.out.println(currency.getCurrencyCode());      // IDR
    System.out.println(currency.getSymbol(indonesia));   // Rp
}

@Test
void testCurrencyUSA() {
    var america = new Locale("en", "US");
    var currency = Currency.getInstance(america);

    System.out.println(currency.getDisplayName());  // US Dollar
    System.out.println(currency.getCurrencyCode()); // USD
    System.out.println(currency.getSymbol(america));// $
}

@Test
void testNumberFormatCurrencyIndonesia() {
    var indonesia = new Locale("in", "ID");
    // Gunakan getCurrencyInstance() bukan getInstance() untuk format mata uang
    var numberFormat = NumberFormat.getCurrencyInstance(indonesia);

    var format = numberFormat.format(1000000.333);
    System.out.println(format); // Output: Rp1.000.000,33
    // Perhatikan: desimal di-round ke 2 digit (standar mata uang)
}

@Test
void testNumberFormatCurrencyParseIndonesia() {
    var indonesia = new Locale("in", "ID");
    var numberFormat = NumberFormat.getCurrencyInstance(indonesia);

    try {
        // Parse string mata uang kembali ke double
        var parse = numberFormat.parse("Rp900.000,25").doubleValue();
        System.out.println(parse); // Output: 900000.25
    } catch (ParseException e) {
        System.out.println("Error parse : " + e.getMessage());
    }
}
Bedah Baris per Baris
KodePenjelasan
Currency.getInstance(locale) Factory method statis. Menggunakan Locale untuk menentukan mata uang yang berlaku di negara tersebut. Mengembalikan singleton per mata uang (IDR, USD, dll) — objek Currency per kode adalah unik.
currency.getDisplayName() Nama mata uang dalam bahasa default JVM. Berguna untuk label di UI.
currency.getCurrencyCode() Kode ISO 4217 (IDR, USD, EUR). Gunakan ini untuk penyimpanan di database, bukan simbol!
currency.getSymbol(locale) Simbol yang ditampilkan untuk locale tertentu. Simbol bisa berbeda per locale untuk mata uang yang sama (misal: $ vs US$ tergantung konteks).
NumberFormat.getCurrencyInstance() Membuat NumberFormat khusus mata uang. Otomatis menambahkan simbol mata uang, menentukan jumlah digit desimal (biasanya 2), dan menggunakan pemisah yang tepat.
✅ Best Practice: Simpan Mata Uang sebagai Kode ISO

Jangan simpan nilai mata uang dengan simbolnya ("Rp1.000.000") di database. Simpan angka murni dan kode ISO secara terpisah: amount = 1000000, currency_code = "IDR". Gunakan getCurrencyCode() untuk mendapatkan kode yang konsisten, dan format hanya untuk tampilan UI.

🔗 Analogi Laravel

Di ekosistem PHP, library seperti moneyphp/money atau brick/money dipakai untuk ini. Di Java, semua sudah built-in di JDK tanpa dependency tambahan. Konsep Currency.getInstance() mirip dengan Money::of(1000000, 'IDR') — kamu tetap perlu mendefinisikan mata uang secara eksplisit, bukan otomatis ditentukan dari setting global.

❌ Salah — Menyimpan simbol di DB
// JANGAN simpan string yang sudah diformat ke DB!
String formatted = numberFormat.format(1000000.333);
database.save(formatted); // "Rp1.000.000,33" — SALAH
// Nanti susah diparse balik, dan tidak portable
✅ Benar — Simpan data mentah
// Simpan angka dan kode mata uang terpisah
double amount = 1000000.333;
String code = Currency.getInstance(locale)
                       .getCurrencyCode(); // "IDR"
database.save(amount, code); // ✅ Portable & parseable

Chapter 5
📅 DateFormat & SimpleDateFormat

SimpleDateFormat memungkinkan kamu memformat dan mem-parsing tanggal dengan pola kustom yang locale-aware. Nama hari dan nama bulan akan otomatis berbeda tergantung locale yang digunakan.

Format Tanggal dengan SimpleDateFormat
// DateFormatTest.java

@Test
void testDateFormat() {
    var pattern = "EEEE dd MMMM yyyy";
    // Tanpa locale → default JVM (biasanya English)
    var dateFormat = new SimpleDateFormat(pattern);
    System.out.println(dateFormat.format(new Date())); // Monday 25 May 2026
}

@Test
void testDateFormatIndonesia() {
    var pattern = "EEEE dd MMMM yyyy";
    var indonesia = new Locale("in", "ID");
    var dateFormat = new SimpleDateFormat(pattern, indonesia);
    System.out.println(dateFormat.format(new Date())); // Senin 25 Mei 2026
}

@Test
void testDateFormatJapan() {
    var pattern = "EEEE dd MMMM yyyy";
    var japan = new Locale("ja", "JP");
    var dateFormat = new SimpleDateFormat(pattern, japan);
    System.out.println(dateFormat.format(new Date())); // 月曜日 25 5月 2026
}

@Test
void testDateFormatParseIndonesia() {
    var pattern = "EEEE dd MMMM yyyy";
    var indonesia = new Locale("in", "ID");
    var dateFormat = new SimpleDateFormat(pattern, indonesia);

    try {
        // Parse dari String format Indonesia ke objek Date
        var date = dateFormat.parse("Rabu 03 Maret 2021");
        System.out.println(date); // Wed Mar 03 00:00:00 WIB 2021
    } catch (ParseException e) {
        System.out.println("Error parse : " + e.getMessage());
    }
}

@Test
void testDateFormatParseJapan() {
    var pattern = "EEEE dd MMMM yyyy";
    var japan = new Locale("ja", "JP");
    var dateFormat = new SimpleDateFormat(pattern, japan);

    try {
        var date = dateFormat.parse("水曜日 03 3月 2021");
        System.out.println(date); // Wed Mar 03 00:00:00 WIB 2021
    } catch (ParseException e) {
        System.out.println("Error parse : " + e.getMessage());
    }
}

🔗 Analogi Laravel

Di Laravel, kamu pakai Carbon::parse('2021-03-03')->locale('id')->isoFormat('dddd DD MMMM YYYY') untuk mendapat nama hari/bulan dalam Bahasa Indonesia. Di Java, SimpleDateFormat dengan Locale Indonesia sudah melakukan hal yang sama. Perbedaannya: Java pakai Date (class lama) sementara Java modern (8+) lebih disarankan pakai LocalDate + DateTimeFormatter dari package java.time — tapi konsepnya sama.

⚠️ SimpleDateFormat Sudah Dianggap Legacy!

Di Java 8+, ada API tanggal yang lebih baik: java.time.LocalDate, LocalDateTime, ZonedDateTime, dan DateTimeFormatter. SimpleDateFormat masih dipakai di banyak kode lawas, tapi untuk kode baru gunakan DateTimeFormatter.ofPattern("EEEE dd MMMM yyyy", locale). API baru ini juga thread-safe — berbeda dengan SimpleDateFormat yang tidak thread-safe.

❌ Legacy (masih valid, tapi hindari)
// SimpleDateFormat — tidak thread-safe
var sdf = new SimpleDateFormat("EEEE dd MMMM yyyy",
    new Locale("in", "ID"));
String result = sdf.format(new Date());
// new Date() juga sudah legacy
✅ Modern Java 8+ (lebih baik)
// DateTimeFormatter — thread-safe, immutable
var formatter = DateTimeFormatter
    .ofPattern("EEEE dd MMMM yyyy",
        new Locale("in", "ID"));
String result = LocalDate.now().format(formatter);
// Lebih aman untuk concurrent use

Chapter 6
💬 MessageFormat

MessageFormat memungkinkan kamu membuat template pesan dengan placeholder yang diisi secara dinamis. Ini adalah fitur inti untuk pesan yang perlu di-localize sekaligus memiliki data dinamis — seperti "Selamat datang, {nama}!"

MessageFormat Dasar
// MessageFormatTest.java

@Test
void testMessageFormat() {
    // {0} adalah placeholder untuk argumen pertama (index dimulai dari 0)
    var pattern = "Hi {0}, Anda bisa mencari data Anda dengan mengetikkan \"{0}\" di pencarian.";
    var messageFormat = new MessageFormat(pattern);

    // format() menerima Object[] — array bisa berisi tipe apa saja
    var format = messageFormat.format(new Object[]{"Eko"});

    System.out.println(format);
    // Output: Hi Eko, Anda bisa mencari data Anda dengan mengetikkan "Eko" di pencarian.
    // {0} yang sama digantikan berkali-kali oleh nilai yang sama ("Eko")
}

    // Pattern diambil dari ResourceBundle:

Bedah Baris per Baris
KodePenjelasan
{0}, {1} Placeholder berindeks (mulai dari 0). Angka menunjukkan posisi argumen dalam array yang dipass ke format(). Placeholder yang sama bisa muncul berkali-kali dalam satu pattern.
new MessageFormat(pattern) Membuat instance dengan pattern. Pattern di-parse dan di-compile saat konstruksi. Kalau pattern salah sintaks, IllegalArgumentException dilempar di sini — bukan saat format().
messageFormat.format(new Object[]{"Eko"}) Parameter adalah Object[] (array of Object). Ini berarti kamu bisa memasukkan tipe apa saja: String, int, Date, dll. Java akan secara otomatis melakukan boxing untuk primitif (int → Integer).
Pattern di ResourceBundle Praktik terbaik: pisahkan pattern dari kode. Simpan di file .properties supaya bisa di-localize tanpa mengubah kode Java. Ini adalah prinsip i18n yang benar.
🔗 Analogi Laravel

Di Laravel kamu menulis: __('messages.welcome', ['name' => 'Eko', 'app' => 'PZN']) dengan file lang: 'welcome' => 'Halo :name, selamat datang di :app'. Di Java, MessageFormat + ResourceBundle bekerja persis sama. Perbedaan sintaks: Laravel pakai :name (named placeholder), Java pakai {0}, {1} (indexed placeholder). Java juga mendukung format lebih kaya dari sekedar string replacement — lihat Chapter 7!

❌ Salah — String concatenation
// JANGAN lakukan ini untuk pesan yang di-localize!

// Masalah: bagaimana dengan bahasa lain?
// "Hello " + name + ", welcome!" harus tulis ulang kode!
✅ Benar — Pakai MessageFormat + ResourceBundle
// Pattern di file .properties, bisa di-localize
// message_in_ID.properties: welcome=Halo {0}!
// message_en_US.properties: welcome=Hello {0}!
var pattern = rb.getString("welcome");
var msg = new MessageFormat(pattern)
    .format(new Object[]{"Eko"});
// Ganti locale → pesan otomatis berubah bahasa!

Chapter 7
🎛️ MessageFormat dengan Tipe & Locale

MessageFormat bisa lebih dari sekedar mengganti placeholder dengan String. Dengan sintaks {index,type,style}, placeholder bisa secara otomatis memformat angka sebagai mata uang, tanggal sebagai tanggal lokal, dan lain-lain — semuanya dalam satu pattern.

Format Tersimpan di ResourceBundle

Contoh pattern di file message_in_ID.properties:

# message_in_ID.properties
status=Halo {0}, tanggal {1,date,EEEE dd MMMM yyyy} saldo Anda adalah {2,number,currency}

# message_en_US.properties
status=Hello {0}, on {1,date,EEEE dd MMMM yyyy} your balance is {2,number,currency}
// MessageFormatTypeTest.java

@Test
void testMessageFormatType() {
    var locale = new Locale("in", "ID");
    var resourceBundle = ResourceBundle.getBundle("message", locale);

    // Pattern: "Halo {0}, tanggal {1,date,EEEE dd MMMM yyyy} saldo Anda adalah {2,number,currency}"
    var pattern = resourceBundle.getString("status");

    // Wajib pass locale ke MessageFormat agar format tanggal/angka ikut locale!
    var messageFormat = new MessageFormat(pattern, locale);
    var format = messageFormat.format(new Object[]{
        "Eko",        // {0} → String biasa
        new Date(),   // {1,date,...} → diformat sebagai tanggal Indonesia
        1000000       // {2,number,currency} → diformat sebagai Rp1.000.000,00
    });

    System.out.println(format);
    // Output: Halo Eko, tanggal Senin 25 Mei 2026 saldo Anda adalah Rp1.000.000,00
}

@Test
void testMessageFormatTypeAmerica() {
    var locale = new Locale("en", "US");
    var resourceBundle = ResourceBundle.getBundle("message", locale);

    var pattern = resourceBundle.getString("status");

    var messageFormat = new MessageFormat(pattern, locale);
    var format = messageFormat.format(new Object[]{
        "Eko",
        new Date(),
        1000000
    });

    System.out.println(format);
    // Output: Hello Eko, on Monday 25 May 2026 your balance is $1,000,000.00
}

💡 Kenapa Harus Pass Locale ke MessageFormat?

Perhatikan: new MessageFormat(pattern, locale) bukan new MessageFormat(pattern). Jika tanpa locale, format tanggal dan angka akan menggunakan locale default JVM (biasanya server Anda, bisa US atau lainnya). Selalu eksplisit pass locale ke MessageFormat ketika pattern mengandung format date/number.

🔗 Analogi Laravel

Di Laravel, kamu butuh kombinasi beberapa hal untuk mencapai ini: __('messages.status', ['name' => 'Eko', 'date' => Carbon::now()->isoFormat('dddd DD MMMM YYYY'), 'balance' => number_format(1000000, 2, ',', '.')]). Di Java, semua formatting itu bisa diinstruksikan langsung dari dalam pattern dengan sintaks {1,date,EEEE dd MMMM yyyy} — lebih ringkas dan locale-aware secara otomatis!

❌ Salah — Lupa pass Locale ke MessageFormat
var locale = new Locale("in", "ID");
var rb = ResourceBundle.getBundle("message", locale);
var pattern = rb.getString("status");

// LUPA pass locale → format pakai JVM default!
var mf = new MessageFormat(pattern); // ← SALAH!
// Tanggal & angka mungkin muncul dalam format US
✅ Benar — Konsisten gunakan locale yang sama
var locale = new Locale("in", "ID");
var rb = ResourceBundle.getBundle("message", locale);
var pattern = rb.getString("status");

// Pass locale → format date & number ikut Indonesia
var mf = new MessageFormat(pattern, locale); // ✅
mf.format(new Object[]{"Eko", new Date(), 1000000});

Chapter 8
🔀 ChoiceFormat

ChoiceFormat memungkinkan pemilihan teks yang berbeda berdasarkan nilai numerik. Ini adalah solusi Java untuk masalah pluralization dan kondisi numerik dalam pesan — seperti "0 item", "1 item", "banyak item". Di Laravel, ini setara dengan helper trans_choice().

ChoiceFormat Langsung
// ChoiceFormatTest.java

@Test
void testChoiceFormat() {
    // Sintaks: "batas#teks | batas#teks | batas1)
    System.out.println(choiceFormat.format(3));  // banyak  (>1)
}
ChoiceFormat di Dalam MessageFormat

Kekuatan sebenarnya adalah menggabungkan ChoiceFormat di dalam MessageFormat via ResourceBundle. Contoh pattern di file properties:

# message_in_ID.properties
balance=Saldo Anda adalah {0,choice,-1#negatif|0#kosong|0<{0,number,currency}}

# message_en_US.properties
balance=Your balance is {0,choice,-1#negative|0#empty|0<{0,number,currency}}
@Test
void testChoiceFormatInMessageFormat() {
    var locale = new Locale("in", "ID");
    var resourceBundle = ResourceBundle.getBundle("message", locale);

    var pattern = resourceBundle.getString("balance");
    var messageFormat = new MessageFormat(pattern, locale);

    System.out.println(messageFormat.format(new Object[]{-1000000}));
    // Output: Saldo Anda adalah negatif

    System.out.println(messageFormat.format(new Object[]{0}));
    // Output: Saldo Anda adalah kosong

    System.out.println(messageFormat.format(new Object[]{1000000}));
    // Output: Saldo Anda adalah Rp1.000.000,00
    // ← Ketika > 0, format sebagai currency!
}

@Test
void testChoiceFormatInMessageFormatAmerica() {
    var locale = new Locale("en", "US");
    var resourceBundle = ResourceBundle.getBundle("message", locale);

    var pattern = resourceBundle.getString("balance");
    var messageFormat = new MessageFormat(pattern, locale);

    System.out.println(messageFormat.format(new Object[]{-1000000}));
    // Output: Your balance is negative

    System.out.println(messageFormat.format(new Object[]{0}));
    // Output: Your balance is empty

    System.out.println(messageFormat.format(new Object[]{1000000}));
    // Output: Your balance is $1,000,000.00
}

🔗 Analogi Laravel

Di Laravel, pluralization dilakukan dengan trans_choice('messages.balance|messages.empty|messages.positive', $count) menggunakan sintaks | di file lang. Di Java, ChoiceFormat lebih fleksibel karena berbasis range numerik, bukan hanya singular/plural. Kamu bisa definisikan kondisi negatif, nol, satu, banyak — semuanya dalam satu pattern string. Plus, bisa dikombinasikan dengan formatter lain (seperti currency) langsung di dalam pattern yang sama.

✅ Best Practice: Taruh Pattern di ResourceBundle

Pattern ChoiceFormat bisa berbeda per bahasa (bahasa tertentu punya aturan pluralisasi yang kompleks). Selalu simpan pattern di file .properties yang terpisah per locale, bukan hard-coded di Java. Ini memungkinkan translator menyesuaikan aturan tanpa mengubah kode.

❌ Salah — Hard-code plural logic di Java
// JANGAN hard-code logika plural di Java!
String msg;
if (count == 0) msg = "kosong";
else if (count == 1) msg = "satu item";
else msg = count + " item";
// Tidak bisa di-localize! Harus ubah kode untuk tiap bahasa
✅ Benar — Pakai ChoiceFormat + ResourceBundle
// Pattern di .properties, diambil via ResourceBundle
// "0#kosong|1#satu item|1<{0} item"
var pattern = rb.getString("item.count");
var mf = new MessageFormat(pattern, locale);
String msg = mf.format(new Object[]{count});
// Translator bisa ubah rule tanpa sentuh kode Java!

📋 Arsitektur Java Internationalization

Berikut adalah gambaran lengkap bagaimana semua komponen i18n di Java bekerja bersama-sama.

Peta Arsitektur Sistem i18n Java

Sistem i18n Java dibangun seperti layer yang saling mendukung:

🌍
Locale — Fondasi Objek value yang mewakili bahasa + negara. Semua komponen lain menerima Locale sebagai parameter. Gunakan new Locale("in", "ID") untuk Indonesia. Ini adalah titik masuk ke seluruh ekosistem i18n.
📦
ResourceBundle — Penyimpan Terjemahan Memuat file .properties berdasarkan Locale dengan mekanisme fallback otomatis. Di-cache oleh JVM, jadi efisien. Analog dengan folder lang/ Laravel.
🔢
NumberFormat — Format Angka Factory class untuk format & parse angka biasa (getInstance) dan mata uang (getCurrencyInstance). Otomatis menentukan pemisah ribuan dan desimal per locale. Tidak thread-safe — buat instance baru setiap kali.
💰
Currency — Informasi Mata Uang Menyediakan kode ISO 4217, nama, dan simbol mata uang dari suatu locale. Singleton per kode mata uang. Gunakan getCurrencyCode() untuk persistensi ke DB.
📅
SimpleDateFormat — Format Tanggal (Legacy) Format tanggal dengan pola kustom yang locale-aware (nama hari/bulan otomatis). Tidak thread-safe. Untuk kode baru, gunakan DateTimeFormatter dari java.time (Java 8+).
💬
MessageFormat — Template Pesan Template string dengan placeholder berindeks ({0}, {1}). Bisa digabungkan dengan format date/number via sintaks {index,type,style}. Selalu pass Locale jika pattern mengandung format date/number.
🔀
ChoiceFormat — Kondisi Numerik Memilih teks berbeda berdasarkan range nilai numerik. Pattern: batas#teks | batas<teks. Bisa di-nested di dalam MessageFormat untuk pluralisasi yang powerful dan locale-aware.

🏆 Checklist Penguasaan Java i18n
  • ✅Paham cara membuat Locale untuk Indonesia ("in","ID") dan negara lain
  • ✅Tahu cara membuat file .properties di src/main/resources/ dan memuatnya dengan ResourceBundle
  • ✅Bisa menggunakan NumberFormat.getInstance() dan getCurrencyInstance() untuk format angka & mata uang
  • ✅Tahu perbedaan format angka Indonesia vs Amerika (titik vs koma sebagai pemisah)
  • ✅Bisa menggunakan SimpleDateFormat dengan Locale untuk format nama hari/bulan dalam berbagai bahasa
  • ✅Paham kenapa SimpleDateFormat legacy dan lebih baik pakai DateTimeFormatter untuk kode baru
  • ✅Bisa membuat template pesan dengan MessageFormat dan mengisi placeholder dengan data dinamis
  • ✅Paham sintaks {index,type,style} di MessageFormat untuk auto-format tanggal dan angka
  • ✅Bisa menggunakan ChoiceFormat untuk pluralisasi dan kondisi numerik dalam pesan
  • ✅Selalu handle ParseException (checked exception) saat menggunakan method parse()
  • ✅Ingat bahwa NumberFormat dan SimpleDateFormat tidak thread-safe
  • ✅Simpan pattern terjemahan di ResourceBundle, bukan hard-coded di kode Java
